# 장비 Hover 스탯 및 장착 장비 비교 Tooltip 설계

## 목표

- 인벤토리의 장비 아이템 Hover 시 해당 장비가 제공하는 능력치 증가량을 표시한다.
- 같은 부위에 장착 중인 장비가 있으면 기존 Tooltip 오른쪽에 현재 장착 장비 카드를 함께 표시한다.
- 교체 시 변화량을 `Hover 장비 - 현재 장착 장비`로 계산해 증가·감소·동일을 구분한다.
- 소비·재료 아이템 Tooltip은 기존 300px 이름·설명·무게 UI를 유지한다.

## 데이터 설계

`URogue10mItemDataAsset`에 `FRogue10mEquipmentStatModifiers` 구조체를 추가한다.

- 공격력: 고정 수치
- 방어력: 고정 수치
- 최대 체력: 고정 수치
- 치명타 확률: 0~1 비율, UI에서는 백분율
- 공격 속도: 가산 배율, UI에서는 백분율
- 이동 속도: 고정 수치

고정 필드 구조를 사용해 동일 스탯 중복 입력을 방지하고, Tooltip과 향후 장비 효과 집계가 같은 의미를 공유하도록 한다.

## UI 설계

- 왼쪽 카드: Hover 아이템 아이콘, 이름, 설명, 무게, `장착 시 증가` 목록
- 오른쪽 카드: `현재 장착` 제목, 장착 아이콘, 이름, 설명, 장착 장비 스탯, `교체 시 변화` 목록
- 동일 부위 장비가 없으면 오른쪽 카드를 `Collapsed` 처리하고 전체 폭을 300px로 유지한다.
- 동일 부위 장비가 있으면 전체 폭을 620px로 확장한다.
- 변화량이 양수면 초록색, 음수면 붉은색, 0이면 회색을 사용한다.
- 두 장비 중 한쪽에만 존재하는 스탯도 비교 목록에 포함해 잃는 능력치를 숨기지 않는다.

## 구현 범위

1. Item Data Asset 장비 스탯 구조 및 스타터 장비 샘플 값 추가
2. Inventory Component의 부위별 장착 Item Data 조회 API 추가
3. Tooltip 초기화 인자에 현재 장착 Item Data 전달
4. 네이티브 Tooltip에서 스탯 행 동적 생성 및 비교 색상 적용
5. `WBP_InventoryItemTooltip` 2열 Designer 구조 재구성
6. Widget Validator에 새 필수 위젯·폭·가시성 계약 추가

## 완료 조건

- 일반 아이템 Tooltip의 기존 정보가 유지된다.
- 장비 Hover 시 장착 증가량이 표시된다.
- 동일 부위 장비가 있을 때만 오른쪽 비교 카드가 표시된다.
- 모든 비교 스탯이 정확한 부호·단위·색상으로 표시된다.
- C++ Editor 빌드와 전체 메뉴 Widget Blueprint 검증이 성공한다.

## 수동 QA

- 장비 미장착 부위 Hover
- 같은 부위 장비 장착 상태 Hover
- 더 좋은 장비, 더 낮은 장비, 동일 수치 장비 비교
- Hover 장비에 없는 스탯을 현재 장비가 제공하는 경우
- 소비 아이템 Hover 회귀 확인
- Tooltip 화면 경계 자동 배치와 Drag 시작 시 Tooltip 제거 확인
