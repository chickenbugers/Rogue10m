# 로비 프리뷰-슬롯 선택 동기화 설계

## 목표

캐릭터 선택 로비에서 캐릭터 프리뷰를 좌클릭하면 같은 인덱스의 하단 캐릭터 슬롯이 선택되도록 한다.

## 범위

- `URogue10mCharacterLobbyWidget`의 마우스 입력 처리
- 기존 슬롯 선택, 삭제, 게임 접속, 더블클릭 접속 흐름 유지
- `WBP_CharacterLobby` 바이너리 자산 구조는 변경하지 않음

## 구현

1. 로비 위젯의 단일 좌클릭을 수신한다.
2. 클릭 좌표가 표시 중인 슬롯 프리뷰 이미지 안인지 판정한다.
3. 대응 슬롯 인덱스를 기존 `SelectSlot()`에 전달한다.
4. 기존 갱신 경로를 통해 하단 슬롯 강조와 선택 프로필을 동기화한다.
5. 더블클릭은 기존처럼 해당 캐릭터로 즉시 접속한다.

## 완료 조건

- 프리뷰 단일 클릭 시 같은 번호의 하단 슬롯이 선택 상태로 표시된다.
- 슬롯 버튼과 프리뷰가 동일한 선택 경로를 사용한다.
- 프리뷰 더블클릭 접속 기능이 유지된다.
- UE 5.8 Editor 타깃 빌드가 성공한다.
