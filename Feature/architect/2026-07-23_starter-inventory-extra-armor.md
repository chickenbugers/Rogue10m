# 시작 인벤토리 추가 갑옷 설계

## 목표

시작 장비 자동 장착은 유지하면서 플레이어 인벤토리에 가죽 갑옷 한 개를 추가로 제공한다.

## 변경 범위

- 기존 `DA_Item_LeatherArmor` Data Asset을 재사용한다.
- 시작 아이템 목록에 가죽 갑옷 참조를 한 번 더 추가한다.
- 동일 부위의 시작 장비가 이미 장착된 경우 후속 장비는 자동 장착하지 않는다.

## Ultrawork Packets

1. 시작 아이템 목록에 가죽 갑옷 한 개를 추가한다.
2. 자동 장착을 부위당 첫 장비로 제한한다.
3. Editor 빌드와 생성 파일 검사를 수행하고 문서를 갱신한다.

## 완료 조건

- 시작 시 Armor 슬롯에는 기존 가죽 갑옷이 장착된다.
- 추가 가죽 갑옷 한 개는 기본 인벤토리 그리드에 남는다.
- 다른 부위의 시작 장비 자동 장착 동작은 유지된다.

## 롤백 경계

시작 아이템 중복 참조와 자동 장착 중복 방지 조건을 함께 되돌리면 기존 동작으로 복구된다.
