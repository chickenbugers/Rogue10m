# Feature Artifacts

Harness-generated planning and development notes live here.

- `architect/`: implementation plans written before larger work starts.
- `doc/`: development summaries written after implementation, build, and review.

Large or unclear work should follow the Lazy Codex overlay:

- Break the feature into Ultrawork Packets.
- Track the ULW loop exit gate in both the architecture plan and development summary.
- See `Docs/LazyCodexHarness.md` for the project-specific rules.

Use:

```powershell
.\Scripts\NewHarnessFeature.ps1 -Name "player combat"
```
