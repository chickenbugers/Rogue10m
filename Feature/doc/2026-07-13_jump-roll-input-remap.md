# 점프·구르기 입력 재배치 결과

- Space에 연결된 `IA_Jump`는 점프 시작과 점프 종료를 호출한다.
- E 키를 누르면 기존 방향 회피 로직을 사용하는 구르기가 실행된다.
- WASD 입력 중에는 해당 방향으로, 입력이 없으면 전방으로 구른다.
- 점프 시작 시 달리기를 종료하며 사망, UI 입력 차단, 구르기 중에는 점프하지 않는다.
- 스킬 슬롯 다섯 번째 안내는 `스페이스 / 점프`로 변경했다.

## 런타임 확인

- Space 홀드 길이에 따른 점프 높이
- E 구르기 방향 및 쿨타임
- 점프 중 E 구르기 허용 여부가 의도와 맞는지 확인
- 공중(CharacterMovement->IsFalling())에서는 E 구르기 입력을 무시한다.
