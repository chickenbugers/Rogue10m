# 캐릭터 기본 스탯 및 장비창 표시 개발 결과

## 결과

캐릭터의 기본 스탯, 장비 보너스, 최종 런타임 스탯의 소유 경계를 정리하고 장비 변경 시 실제 전투·생존·이동 수치와 장비창 표시가 함께 갱신되도록 구현했다.

## 기본 스탯

`DA_Character_Default`가 장비 적용 전 기준값을 소유한다.

| 스탯 | 기본값 |
| --- | ---: |
| 최대 체력 | 100 |
| 최대 스테미나 | 100 |
| 최대 마나 | 100 |
| 공격력 | 10 |
| 방어력 | 0 |
| 치명타 확률 | 5% |
| 치명타 피해 배율 | 150% |
| 공격 속도 배율 | 100% |
| 이동 속도 | 600 cm/s |
| 질주 속도 | 900 cm/s |

## 데이터 흐름

1. `URogue10mCharacterDataAsset`이 기본 스탯을 제공한다.
2. `URogue10mInventoryComponent`가 현재 장착된 Item Data Asset의 장비 보너스를 합산한다.
3. `ARogue10mCharacter::GetCharacterStatSnapshot()`이 기본·장비·최종 스탯을 한 번에 계산한다.
4. `RefreshCharacterStats()`가 최종값을 PlayerState의 `URogue10mAttributeSet`과 `CharacterMovement`에 반영한다.
5. `URogue10mEquipmentWindowWidget`은 동일한 스냅샷으로 `최종 (기본 + 장비)` 값을 표시한다.

장착·장착 해제의 모든 성공 경로는 공통 `NotifyEquipmentChanged()`를 거쳐 런타임 스탯을 먼저 갱신한 뒤 UI Delegate를 방송한다.

## 적용 공식

- 최종 공격력 = 기본 공격력 + 장비 공격력
- 스킬 피해 = `(스킬 기본 피해 + 최종 공격력) × 피해 변동 배율`
- 최종 방어력 = 기본 방어력 + 장비 방어력
- 적용 피해 = `max(1, 입력 피해 - 최종 방어력)`
- 최종 최대 체력 = 기본 최대 체력 + 장비 최대 체력
- 최종 치명타 확률 = `clamp(기본 + 장비, 0%, 100%)`
- 최종 공격 속도 = `clamp(기본 배율 + 장비 배율, 10%, 500%)`
- 최종 이동·질주 속도 = 각 기본 속도 + 장비 이동 속도

장비로 최대 체력이 바뀔 때는 현재 체력 비율을 보존한다. 최초 ASC 초기화에서는 최대치까지 회복한다.

## 장비창 표시

장비창에는 다음 6개 항목을 표시한다.

- 공격력
- 방어력
- 최대 체력
- 치명타 확률
- 공격 속도
- 이동 속도

예: `공격력 25 (기본 10 + 장비 15)`. 장비 보너스가 0이면 기본값만 표시한다.

현재 시작 자동 장착 구성을 기준으로 예상되는 최종값은 공격력 25, 방어력 20, 최대 체력 135, 치명타 확률 10%, 공격 속도 104%, 이동 속도 620이다.
