# 로비 프리뷰-슬롯 선택 동기화 개발 결과

## 결과

캐릭터 선택 로비에서 캐릭터 프리뷰를 좌클릭하면 같은 인덱스의 하단 캐릭터 슬롯이 선택되도록 구현했다.

## 주요 변경

- `NativeOnMouseButtonDown()`에서 프리뷰 단일 좌클릭을 처리한다.
- 표시 중인 슬롯 프리뷰의 화면 좌표를 슬롯 인덱스로 변환한다.
- 프리뷰 클릭과 하단 슬롯 버튼이 기존 `SelectSlot()`을 공통으로 사용한다.
- 선택 프로필, 슬롯 강조, 삭제 대상, 게임 접속 대상이 함께 갱신된다.
- 기존 프리뷰 더블클릭 즉시 접속 기능은 같은 좌표 판정 함수를 사용하도록 정리했다.
- 캐릭터 생성 화면에서는 슬롯 프리뷰 선택을 처리하지 않는다.

## 검증

- UE 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- `Scripts/CheckGeneratedChanges.ps1` 통과
- `git diff --check` 통과
- 생성 파일과 캐시 파일 변경 없음

## 수동 QA

1. Menu Map에서 게임 시작을 눌러 Lobby로 이동한다.
2. 첫 번째, 두 번째, 세 번째 캐릭터 프리뷰를 각각 한 번 클릭한다.
3. 클릭한 캐릭터와 같은 번호의 하단 슬롯 배경이 선택 색상으로 바뀌는지 확인한다.
4. 선택 후 캐릭터 삭제 및 게임 접속 대상이 일치하는지 확인한다.
5. 프리뷰 더블클릭으로 즉시 게임에 접속되는지 확인한다.
