# Rogue10m

## Game Design Document (GDD)

- **문서 버전:** v0.1
- **작성 기준:** 현재 대화에서 확인된 Rogue10m 프로젝트의 게임 구조, 시스템 구성 및 UI 정보를 기반으로 작성한 초안
- **개발 엔진:** Unreal Engine 5.8

---

## 1. 게임 개요

### 1.1 프로젝트 정보

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | Rogue10m |
| 장르 | First-Person Action Roguelike RPG |
| 엔진 | Unreal Engine 5.8 |
| 플랫폼 | PC 메인, 모바일 플레이 지원 목표 |
| 플레이 인원 | 1인 |

| 입력 방식 | PC: Keyboard + Mouse / 모바일: 터치 입력 목표 |

## 2. 게임 비전

Rogue10m은 30분~1시간의 세션 안에서 강한 성장 체감을 제공하는 1인칭 액션 로그라이크 RPG이다.

플레이어는 반복 플레이를 통해 다양한 성장 조합을 구성하고, 매 플레이마다 다른 전투 경험을 얻게 된다.

### 2.1 핵심 목표

- 빠른 전투 템포
- 강한 성장 체감
- 단순하지만 깊이 있는 빌드 구성
- 부담 없이 반복할 수 있는 30분~1시간의 세션

## 3. 핵심 게임 루프

1. 게임 시작
2. 캐릭터 생성
3. 전투
4. 경험치 획득
5. 레벨업
6. 성장 선택
7. 강화된 상태로 전투 지속
8. 보스 전투
9. 클리어 또는 사망
10. 결과 화면 확인
11. 재도전

## 4. 플레이어 시스템

### 4.1 Player Character

플레이어가 직접 조작하는 캐릭터이다.

#### 주요 역할

- 이동
- 전투
- 성장
- 아이템 사용

### 4.2 이동 시스템

#### 목표

빠르고 직관적인 이동 조작을 제공한다.

#### 이동 입력

- WASD 이동
- 마우스로 시점 및 방향 조작
- 모바일에서는 가상 조이스틱과 터치 입력 지원을 목표로 함

#### 이동 처리

- Character Movement Component 기반 이동
- 1인칭 카메라 방향을 기준으로 이동 방향 계산

#### 이동 상태

- Idle
- Move
- Knockback
- Dead

### 4.3 회전 시스템

캐릭터의 방향을 1인칭 카메라 및 조준 방향과 동기화한다.

#### 목적

- 공격 방향 결정
- 이동 방향 표현

## 5. 전투 시스템

### 5.1 전투 목표

플레이어가 지속적으로 공격과 성장을 반복하도록 유도하고, 빠른 템포의 전투 경험을 제공한다.

### 5.2 공격 시스템

#### 기본 공격

플레이어의 입력에 따라 적을 공격한다. 자동 공격은 지원하지 않는다.

#### 처리 과정

1. 공격 시작
2. 타격 판정
3. 피해 계산
4. 피해 적용
5. 사망 판정

### 5.3 다단 히트 시스템

Combat Component를 기반으로 한 공격 처리 시스템이다.

#### 주요 데이터

| 항목 | 설명 |
| --- | --- |
| `HitCount` | 전체 타격 횟수 |
| `HitInterval` | 각 타격 사이의 시간 간격 |
| `Damage` | 타격당 피해량 |

#### 처리 흐름

1. `StartAttackHitSequence()` 호출
2. 공격 Execution 생성
3. 첫 타격 실행
4. 타이머 등록
5. 설정된 간격에 따라 추가 타격 실행
6. 전체 타격 완료 후 종료

### 5.4 피해 시스템

#### 계산 순서

1. 기본 피해량 산출
2. 공격력 보정 적용
3. 방어력 적용
4. 최종 피해량 산출
5. 대상의 HP 감소
6. 사망 여부 판정

### 5.5 상태이상 시스템(예정)

#### 후보 상태이상

- Stun
- Slow
- Burn
- Poison
- Freeze

## 6. 성장 시스템

### 6.1 경험치

#### 획득 방법

- 몬스터 처치
- 이벤트 보상

### 6.2 레벨업

경험치가 최대치에 도달하면 레벨업이 발생한다.

#### 레벨업 보상

- 능력치 증가
- 일반 신규 스킬 획득
- 기존 스킬 강화

일부 신규 스킬은 일반 레벨업 선택지에 등장하지 않으며, 스킬북 사용이나 퀘스트 완료를 통해 해금 또는 획득해야 한다.

### 6.3 Progression System

#### 목적

플레이 중 캐릭터의 성장 상태와 성장 체감을 명확하게 전달한다.

#### 관련 UI

- Progression Widget

#### 표시 정보

- 현재 레벨
- 현재 경험치
- 다음 레벨까지 필요한 경험치
- 성장 상태

## 7. 스킬 시스템

### 7.1 목표

플레이어가 다양한 조합을 구성할 수 있도록 빌드 다양성을 제공한다.

### 7.2 Active Skill

플레이어가 직접 입력하여 사용하는 스킬이다.

#### 구성 데이터

- `SkillId`
- `Name`
- `Cooldown`
- `Damage`
- `HitCount`
- `HitInterval`

#### 기능 예시

- 즉시 발동
- 범위 공격
- 투사체 공격

### 7.3 스킬 획득 경로

- 레벨업 성장 선택을 통한 일반 스킬 획득
- 스킬북 사용을 통한 특정 스킬 획득
- 퀘스트 완료를 통한 특정 스킬 해금 또는 획득
- 이미 보유한 스킬의 레벨업 및 강화

### 7.4 Passive Skill

획득 후 지속적으로 효과가 적용되는 스킬이다.

#### 효과 예시

- 공격력 증가
- 치명타 확률 증가
- 공격속도 증가
- 생존력 증가

## 9. 아이템 시스템

### 9.1 목표

아이템 획득과 선택을 통해 성장 방식의 다양성을 제공한다.

### 9.2 아이템 종류

#### 소비 아이템

- 획득 후 즉시 또는 필요할 때 사용

#### 장비 아이템

- 장착하여 능력치 또는 특수 효과 적용

#### 특수 아이템

- 세션 내 로그라이크 강화 효과 제공

### 9.3 획득 방법

- 몬스터 드롭
- 스테이지 및 이벤트 보상
- 상점 구매

## 10. 장비 시스템

### 10.1 목표

장비 획득과 교체를 통해 캐릭터의 전투 능력을 강화한다.

### 10.2 장비 슬롯

#### 무기

- 공격력 증가
- 공격 방식 또는 공격 효과 변경

#### 방어구

- 방어력 및 생존력 증가

#### 장신구

- 특수 효과 및 보조 능력 제공

### 10.3 장비 흐름

1. 장비 획득
2. 인벤토리에 저장
3. 장비 장착
4. 능력치 또는 효과 적용
5. 장비 교체 또는 해제 시 기존 효과 제거
