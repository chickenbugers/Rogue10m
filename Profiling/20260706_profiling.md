# 2026-07-06 프로파일링 기록

## 측정 목적

- Rogue10m의 현재 HUD, UI 위젯, 전투 기본 시스템, 맵 이동 구조가 성능에 주는 영향을 기록하기 위한 기준 파일이다.
- 아직 실제 측정값이 입력되지 않은 초기 템플릿이며, 에디터 또는 패키징 빌드에서 측정 후 값을 채운다.

## 측정 시나리오

### 1. 기본 HUD 상태

- 조건: 캐릭터 스폰 후 이동하지 않고 기본 HUD만 표시한다.
- 확인 항목: 체력, 스테미나, 아이덴티티, 스킬 슬롯, 시스템 로그, 미니맵 비용.
- 결과: 미측정

### 2. UI 패널 표시 상태

- 조건: 인벤토리, 장비창, 스킬트리, 설정창을 각각 열고 닫는다.
- 확인 항목: Widget Blueprint 표시 시 Slate 비용, 입력 모드 전환, 캐릭터 이동 차단 처리.
- 결과: 미측정

### 3. 전투 입력 상태

- 조건: 기본 좌클릭, 우클릭, 점프 공격, 차지 공격, 콤보 공격을 반복한다.
- 확인 항목: 공격 Data Asset 접근, 쿨타임 UI 갱신, 디버그 표시, 피격/타격 표시 비용.
- 결과: 미측정

### 4. 몬스터 전투 상태

- 조건: 기본 몬스터를 바라보고 전투를 진행한다.
- 확인 항목: 몬스터 정보 UI, 데미지 표시, AI 이동, 피격 처리.
- 결과: 미측정

### 5. 맵 이동 상태

- 조건: 시작 맵에서 포탈을 통해 플레이 맵으로 이동한다.
- 확인 항목: 20분 타이머 UI 활성화, 맵 로딩 이후 HUD 상태, 메모리 변화.
- 결과: 미측정

## 개선 작업 후보

- Widget Blueprint 내부에서 불필요하게 Tick되는 위젯이 있는지 확인한다.
- 스킬 슬롯과 아이템 슬롯은 변경 이벤트 기반으로 갱신하고 매 프레임 전체 재생성을 피한다.
- 몬스터 정보 UI는 타겟 변경 시에만 갱신하고, 매 프레임 텍스트 재생성을 제한한다.
- 모바일 모드에서는 VFX, 미니맵, Slate 비용을 별도로 측정한다.

- Rogue10m 프로파일링 기록은 `Profiling/YYYYMMDD_profiling.md` 형식으로 관리한다.
