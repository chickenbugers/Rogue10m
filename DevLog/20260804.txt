# 2026-08-04 Rogue10m 개발 기록

## 로비 캐릭터 프리뷰와 하단 슬롯 선택 동기화

### 작업 배경

캐릭터 선택 로비에서 하단 정보 슬롯은 클릭할 수 있었지만, 캐릭터 프리뷰 자체를 한 번 클릭했을 때는 선택 상태가 변경되지 않았다. 프리뷰 더블클릭 접속만 별도로 처리되고 있어 단일 클릭과 하단 슬롯의 사용자 경험이 일치하지 않았다.

### 구현 내용

- 로비 위젯에 단일 좌클릭 입력 처리를 추가했다.
- 클릭 좌표가 세 캐릭터 프리뷰 중 어느 영역에 포함되는지 판정한다.
- 대응하는 슬롯 인덱스를 기존 `SelectSlot()` 함수에 전달한다.
- 프리뷰와 하단 슬롯 버튼이 동일한 선택 프로필 및 UI 갱신 경로를 사용하도록 통합했다.
- 기존 프리뷰 더블클릭 즉시 접속 기능을 유지했다.
- 캐릭터 생성 화면에서는 슬롯 선택 입력을 무시하도록 경계를 유지했다.

### 검증 결과

- Unreal Engine 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- Harness 생성 파일 검사 통과
- Git 공백 및 패치 검사 통과
- 생성물, 캐시, Blueprint 바이너리 변경 없음

### 남은 확인

- Menu Map PIE에서 프리뷰 단일 클릭과 하단 슬롯 강조 상태를 수동 확인한다.
- 프리뷰 더블클릭 접속 및 선택 캐릭터 삭제 대상을 함께 확인한다.

## [Notion 요약 후보]

캐릭터 선택 로비의 프리뷰 단일 클릭을 기존 슬롯 선택 로직에 연결했다. 이제 캐릭터 모델을 클릭해도 같은 인덱스의 하단 슬롯이 선택되고, 선택 강조·삭제·게임 접속 대상이 함께 동기화된다. 더블클릭 즉시 접속 기능과 캐릭터 생성 화면의 입력 경계는 유지했으며 UE 5.8 Editor 빌드와 Harness 검사를 통과했다.
