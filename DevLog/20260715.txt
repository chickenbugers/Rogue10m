# 2026-07-15 개발 기록

## Sprint#1-13 메뉴 UserWidget Designer 직접 배치

### 작업 목적

인벤토리, 장비창, 스킬 트리 UI가 C++에서 Slate 위젯을 런타임 생성하지 않고 Widget Blueprint Designer에서 직접 편집 가능한 구조가 되도록 변경했다.

### 주요 변경 사항

- WBP 4종의 Designer 트리를 Unreal Editor API로 생성·컴파일·저장했다.
- 인벤토리에 Grid, NxM 아이템 Canvas, 하단 돈·무게 정보를 직접 배치했다.
- 장비창에 캐릭터 프리뷰, 장비 슬롯 7종, 능력치 영역을 배치했다.
- 스킬 엔트리를 반복용 UserWidget으로 구성하고 스킬 트리에 필터, 스크롤 목록, 스킬 포인트 영역을 배치했다.
- Overlay 없이 Canvas 형제 배치와 ZOrder로 인벤토리 셀/아이템 표시 순서를 구성했다.
- C++ `RebuildWidget()` UI 생성 코드를 제거하고 필수 위젯을 `BindWidget`으로 강제했다.
- Editor 자동화에 필수 이름 및 Overlay 미사용 검증을 추가했다.

### 검증 결과

- Rogue10mEditor Win64 Development 빌드 성공
- 네 Widget Blueprint 컴파일 및 저장 성공
- 필수 위젯 누락 0개, Overlay 0개
- Inventory 8개, InventoryCell 2개, Equipment 23개, SkillTreeEntry 8개, SkillTreeWindow 11개 위젯 확인

### 주의 사항

필수 BindWidget 이름이나 타입을 Designer에서 바꾸면 Widget Blueprint 컴파일이 실패한다. 스타일 변경은 WBP에서 진행하고, 데이터·입력·Drag & Drop 동작은 C++에 유지한다.

## Inventory UserWidget 후속 개선

### 변경 사항

- `UI_BagTabContainer`, `UI_InventoryCapacityText`, `UI_InventoryHintText`를 제거했다.
- `WBP_InventoryCell` UserWidget을 추가했다.
- Inventory Container의 GridSize X×Y만큼 셀을 Construct/창 열기/Grid 변경 이벤트에서 자동 생성하도록 구현했다.
- `UI_InventoryGrid`는 셀 좌표와 Drop 기준, `UI_InventoryItemCanvas`는 NxM 아이템 표시와 Drag & Drop을 담당하도록 역할을 분리했다.
- 하단에 `UI_InventoryMoneyText`와 `UI_InventoryWeightText`를 배치했다.
- Item Data Asset에 기본 0.1kg의 `UnitWeight`를 추가했다.
- 전체 컨테이너의 아이템 무게×수량을 합산해 현재 무게를 계산하고, 기본 최대 무게 100kg과 함께 표시한다.
- 무게 초과 시 획득 제한은 아직 적용하지 않고 표시 데이터만 구성했다.

### 검증

- Rogue10mEditor Win64 Development 빌드 성공
- 열린 Editor Remote Execution으로 WBP 5종 컴파일·저장 성공
- Inventory 필수 위젯 4개, 제거 대상 0개, Overlay 0개 확인
- `InventoryCellWidgetClass = WBP_InventoryCell_C` 연결 확인
- Python 문법 검사 성공
