## NxM 그리드 인벤토리와 메뉴 창 기반

### 구현 내용

- 인벤토리, 장비, 스킬트리 전용 UserWidget 부모와 I/B/K 창 토글 기반을 추가했다.
- 기본 인벤토리를 10x10으로 구성하고 NxM 아이템의 범위 및 충돌 검사를 구현했다.
- GUID 기반 아이템 추가, 이동, 제거와 Blueprint 갱신 이벤트를 제공한다.
- 가방 Item Data Asset을 통해 별도의 추가 인벤토리 컨테이너를 등록할 수 있다.
- Item Data Asset에 아이템 ID, 이름, 설명, 아이콘, 등급, 분류, 장비 정보, NxM 크기, 최대 스택, 월드 Mesh, 드롭 허용, 가방 크기를 정의했다.
- 아이템을 버리면 Data Asset의 Mesh와 이름을 가진 DroppedItem을 서버에서 생성하며 Spawn 실패 시 원래 위치로 복원한다.
- 기존 프로토타입 ItemSlots와 장비 및 소비 퀵슬롯 API는 호환성을 위해 유지했다.

### Notion 요약 후보

> 마비노기 방식의 NxM 그리드 인벤토리 기반을 도입했다. 기본 10x10 공간과 가방별 추가 컨테이너, Data Asset 기반 아이템 정의, 월드 드롭 Mesh, 메뉴 UserWidget 토글 구조를 C++에서 제공한다.
## 몬스터 데이터 에셋·자원 회복·HUD 정리

### 작업 내용
- 몬스터 이름, 레벨, 경험치 보상, 최대 체력/스테미나/마나, 초당 회복량, Skeletal Mesh, Anim Blueprint, 이동/감지/공격 설정을 포함하는 Monster Data Asset 타입을 추가했다.
- 플레이어와 몬스터 공용 자원 회복 컴포넌트를 추가하고 Tick 없이 1초 타이머로 각 자원을 기본 초당 0.1 회복하도록 구성했다.
- MonsterInfo를 LV N : 몬스터 이름과 체력 게이지/정수 체력 중심으로 정리하고 속성 텍스트 의존성을 제거했다.
- MainWidget의 MiniMap 갱신과 프로토타입 패널 생성을 임시 비활성화했다.
- 아이템 획득 성공 시 아이콘과 수량을 피드에 전달하고 이미지 | x수량 형식으로 표시하도록 연결했다.
- 현재 프로그램 구조와 주요 기능 흐름을 Mermaid로 문서화했다.

### 검증

### Notion 요약 후보

## 스킬트리 Drag and Drop Loadout과 무기별 회피 데이터화

### 작업 내용
- CombatComponent 생성자에 있던 특정 AttackSkill Data Asset 경로 하드코딩을 제거했다.
- 무기별 기본 공격 스킬, 스킬트리 후보, 초기 해금 스킬, 기본 회피를 묶는 Weapon Skill Profile Data Asset 타입을 추가했다.
- 회피 거리, 지속시간, 쿨다운, 스테미나 비용, 아이콘을 가진 Dodge Skill Data Asset 타입을 추가하고 기본 이동 거리를 1m로 지정했다.
- 무기 장착 상태가 바뀌면 현재 WeaponType의 기본 공격 Loadout과 회피기를 자동 적용하도록 연결했다.
- 해금된 스킬트리 엔트리를 Drag하고 좌/우 클릭 및 차징 HUD 슬롯에 Drop해 장착할 수 있도록 네이티브 UMG 기반을 추가했다.
- E 회피 슬롯은 무기 프로필의 자동 바인딩 결과를 표시하며 수동 Drop을 받지 않도록 구성했다.
- Data Asset 생성 위치와 BP_FirstPersonCharacter, 스킬트리 WBP 연결 방법을 별도 가이드로 정리했다.

### 검증
- UE 5.8 UnrealHeaderTool 성공.
- Rogue10mEditor Win64 Development 빌드 성공.
- Tick 추가 없음.

### Notion 요약 후보
> 공격 스킬의 고정 경로 참조를 무기별 Skill Profile Data Asset으로 교체했다. 스킬트리에서 해금된 스킬을 입력 슬롯에 Drag and Drop할 수 있고, E 회피는 현재 무기 프로필의 기본 회피 Data Asset을 자동 사용하며 기본 이동 거리는 1m이다.
