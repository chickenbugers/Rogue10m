# 2026-07-29 Rogue10m 개발 로그

## Sprint#3-5 보완 - UIOnly 포커스 오류 수정

### 문제

게임 시작 시 `FInputModeUIOnly`가 포커스 불가능한 Main Menu의 `SObjectWidget`을 포커스 대상으로 전달해 다음 로그가 발생했다.

`LogPlayerController: Error: InputMode:UIOnly - Attempting to focus Non-Focusable widget SObjectWidget`

### 원인과 수정

- 캐릭터 로비는 `NativeConstruct()`에서 이미 포커스 가능 상태였다.
- 메인 메뉴 위젯에는 동일한 설정이 없어 `MainMenuWidget->TakeWidget()`이 포커스를 받을 수 없었다.
- `URogue10mMainMenuWidget::NativeConstruct()`에 `SetIsFocusable(true)`를 추가했다.
- 기존 게임 시작·종료 버튼과 Main Menu → Lobby 흐름은 유지했다.

### 검증

- UE 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- 수정 파일: `Source/Rogue10m/UI/Widgets/Rogue10mMainMenuWidget.cpp`
- PIE에서 게임 시작 직후 해당 로그가 다시 발생하지 않는지 최종 확인 필요
## Sprint#3-5 보완 - 캐릭터 슬롯 입력과 프리뷰 복구

### 원인

- `UI_BottomBar`가 버튼보다 높은 ZOrder에서 Hit Test를 가로막아 슬롯·삭제·접속 버튼이 동작하지 않았다.
- 프리뷰 액터는 메시와 조명을 끈 상태에서 먼저 Render Target을 캡처했고, 로비가 게임을 일시정지해 활성화 이후 캡처가 갱신되지 않았다.
- 배경 Image가 고정 1920×1080 슬롯을 사용해 실제 뷰포트 비율에서 빈 영역이 생겼다.

### 수정

- 슬롯 및 주요 액션 버튼 ZOrder를 8로 상향
- BottomBar, Shade, Stage Preview를 SelfHitTestInvisible로 변경
- 성 배경 Image 유지, 전체 화면 Stretch 앵커와 0 오프셋 적용
- SceneCapture와 SkeletalMesh에 일시정지 중 갱신 허용
- 메시·조명 활성화 후 즉시 수동 캡처
- Retarget AnimBP 누락 시 기준 포즈 표시와 오류 로그 추가
- 열린 Unreal Editor에 공식 Python Remote Execution으로 PIE 종료 및 WBP 재구성

### 검증

- UE 5.8 Rogue10mEditor Win64 Development 빌드 성공
- 현재 Editor 메모리에서 Character Selection Stage Validator 통과
- Validator 확인: 배경 Image 부재, 단색 Backdrop, 장식 Hit Test 비활성, 버튼 ZOrder 8, 3개 Slot Preview
- 새 C++ DLL 적용을 위해 Unreal Editor 재시작 필요
### 배경 요구사항 정정

사용자 의도에 맞춰 배경 이미지는 삭제하지 않고 유지했다. `UI_LobbyBackgroundImage`는 Canvas 최소 앵커 `(0,0)`, 최대 앵커 `(1,1)`, 좌·상·우·하 오프셋 `0`으로 설정해 뷰포트 전체를 채운다. Image는 `SelfHitTestInvisible`이므로 슬롯과 액션 버튼 입력을 차단하지 않는다.
## Sprint#3-5 보완 - 캐릭터 프리뷰 로드 및 인게임 이동 복구

### 원인

- 프리뷰용 Manny 메시가 패키지 경로(`/Game/.../SKM_Manny_Simple`)로만 지정되어 `TSoftObjectPtr::LoadSynchronous()`가 오브젝트를 찾지 못했다.
- Main Menu와 Character Lobby 진입 과정에서 이동·시점 입력 차단 카운터가 중복 증가했고, 캐릭터 접속 시 한 단계만 해제되어 WASD 입력이 계속 차단되었다.

### 수정

- 프리뷰 소스 메시를 전체 오브젝트 경로 `/Game/Characters/Mannequins/Meshes/SKM_Manny_Simple.SKM_Manny_Simple`로 변경했다.
- 프리뷰 로드 실패 로그에 메시와 AnimBP 경로를 함께 출력하도록 개선했다.
- 메뉴 및 로비의 입력 차단은 이미 차단된 경우 중복 적용하지 않도록 보호했다.
- 캐릭터 접속 시 `ResetIgnoreMoveInput()`과 `ResetIgnoreLookInput()`으로 누적된 입력 차단을 전부 해제한다.
- 접속 직후 Pawn, 이동/시점 차단, 일시정지 상태를 `Gameplay input restored` 로그로 출력한다.

### 검증

- UE 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- 현재 에디터가 열린 상태에서 새 DLL이 생성되었으므로 에디터 재시작 후 PIE 체감 확인 필요
- 기대 로그: `Gameplay input restored. ... MoveIgnored=0 LookIgnored=0 Paused=0`

### Notion 요약 후보

캐릭터 로비 프리뷰의 Manny 메시 경로를 UE 전체 오브젝트 경로로 수정하고, Main Menu → Lobby 과정에서 누적되던 입력 차단 카운터를 방지했다. 인게임 접속 시 이동·시점 차단을 완전히 초기화하여 WASD 입력이 복구되도록 했다.
## Sprint#3-6 - Menu Map 기반 UI와 인게임 전환

### 목표

메인 메뉴와 캐릭터 선택 UI를 인게임 맵에서 분리하고, 별도 Menu Map에서 전체 화면으로 표시한 뒤 선택 캐릭터와 함께 인게임 맵으로 이동한다.

### 구현

- `/Game/Rogue10m/Maps/L_Menu` 맵을 새로 생성했다.
- `ARogue10mMenuGameMode`와 `ARogue10mMenuPlayerController`를 추가했다.
- Menu Map에서는 Pawn, HUD, Spectator를 생성하지 않고 Main Menu와 Character Lobby만 초기화한다.
- 캐릭터 접속 시 선택 프로필을 유지한 채 `/Game/FirstPerson/Lvl_FirstPerson?StartRun=1`을 연다.
- 인게임 GameMode가 선택된 종족·성별 CharacterClass를 Spawn/Possess한다.
- 프로젝트 `EditorStartupMap`과 `GameDefaultMap`을 `L_Menu`로 변경했다.
- Main Menu 배경과 Shade를 전체 화면 Stretch로 변경했다.
- 제목, 부제, 시작·종료 버튼을 확대했다.
- 원격 자산 작업 전 PIE를 종료하는 공통 실행 도우미를 추가했다.

### 검증

- UE 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- Menu Map/World Settings/Gameplay Map/UI Stretch Validator 통과
- 기존 Menu → Lobby 위젯 경로와 버튼 바인딩 Validator 통과
- 실제 PIE: `L_Menu → Lobby → Lvl_FirstPerson` 이동 성공
- 생성 Pawn: `BP_Rogue10m_HumanMaleCharacter_C`
- 입력 상태: `MoveIgnored=False`, `LookIgnored=False`, `Paused=False`

### Notion 요약 후보

메인 메뉴와 캐릭터 선택을 독립된 `L_Menu` 맵으로 분리했다. Menu 전용 GameMode와 Controller는 Pawn/HUD 없이 전체 화면 UI만 초기화하며, 캐릭터 접속 시 선택 프로필을 유지하고 `Lvl_FirstPerson?StartRun=1`으로 이동한다. 실제 PIE에서 선택 캐릭터 Spawn/Possess와 WASD 입력 복구까지 검증했다.

## Sprint#3-6 - 로비 캐릭터 프리뷰 정면 고정 및 투명 합성

### 요구사항

- 세 캐릭터 프리뷰를 모두 정면으로 고정
- 프리뷰 세로 크기와 배치 통일
- 검은 프리뷰 배경과 로비 배경 음영 제거
- Lobby 회전 입력 제거, 장비창에서만 회전 허용

### 구현

- ARogue10mCharacterCustomizationPreviewActor의 프리뷰 기준 Yaw를 -90도로 고정했다.
- Scene Capture를 SCS_SceneColorHDR로 변경하고 RGBA16f Render Target에 Inverse Opacity를 보존했다.
- /Game/Material/UI/M_CharacterPreviewTransparent UI Translucent 머티리얼을 추가했다.
- 로비 위젯이 Render Target별 MID를 만들고 PreviewTexture로 연결하도록 변경했다.
- 세 Slot Preview를 Y=15, 360×720으로 통일했다.
- UI_Slot1~3StageGlow를 제거하고 UI_BackgroundShade 알파를 0으로 변경했다.
- 로비의 마우스 드래그 회전 처리와 상태를 제거했다.
- 더블클릭 캐릭터 접속과 장비창 전용 회전 구현은 유지했다.

### 검증

- UE 5.8 Rogue10mEditor Win64 Development 빌드 성공
- Character Selection Stage Validator: Success, 오류 0건
- Character Lobby Flow Suite: Success, 오류 0건
- 투명 머티리얼, 동일 360×720 프레임, 필수 바인딩 및 기존 로비 흐름 확인
