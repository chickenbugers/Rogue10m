# 2026-07-22 개발 로그

## 장비 장착 해제 컨텍스트 메뉴 UX 개선

### 작업 목표

장비창에서 장착 아이템을 우클릭할 때 기존 Hover Tooltip과 장착 해제 메뉴가 겹치지 않게 하고, 메뉴를 커서 오른쪽에 표시하며 메뉴 외부 클릭으로 닫히도록 개선했다.

### 주요 변경 사항

- 우클릭 순간 활성 Slate Tooltip을 즉시 닫도록 처리했다.
- 메뉴가 열려 있는 동안 해당 슬롯 Tooltip을 억제하고 메뉴 종료 시 최신 데이터로 복원했다.
- 장착 해제 메뉴를 커서 오른쪽 12px 위치에 배치하고 Viewport 경계를 보정했다.
- 장착 해제 WBP에 전체 화면 투명 dismiss 버튼을 추가했다.
- 메뉴 외부 첫 클릭을 dismiss 버튼이 소비해 뒤 UI나 게임 입력이 함께 실행되지 않게 했다.
- 메뉴 생성 스크립트와 전체 메뉴 Validator의 필수 위젯 목록을 갱신했다.

### 검증 결과

- Rogue10mEditor Win64 Development 빌드 성공
- WBP_EquipmentSlotAction 재생성 및 저장 성공
- 전체 메뉴 Widget Validator 0 errors / 0 warnings
- Python 문법 검사와 git diff 공백 검사 통과
- 생성·캐시 파일 변경 검사 통과

### 수동 확인 필요

- PIE에서 Tooltip에서 우클릭 메뉴로 전환되는 순간의 표시 상태
- 화면 가장자리에서 메뉴 위치 보정
- 메뉴 내부 클릭 유지와 외부 클릭 닫기
- 메뉴 닫힌 뒤 Hover Tooltip 복원

## Notion 요약 후보

장비창 우클릭 UX를 개선했다. Hover Tooltip은 우클릭 즉시 숨기고, 장착 해제 메뉴는 커서 오른쪽에 표시한다. Action Widget에 전체 화면 투명 dismiss surface를 추가해 메뉴 외부 첫 클릭으로 안전하게 닫히며, 해당 클릭이 뒤 UI나 게임 입력에 전달되지 않도록 했다. 메뉴 종료 시 장비 슬롯 Tooltip 연결은 최신 데이터로 복원된다.
