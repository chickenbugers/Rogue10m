# 설정 패널 의사코드

Input:
  PlayerController가 O, Escape, F10 입력 처리
  SettingsVisible 토글
  열리면 마우스와 GameAndUI 입력 모드 활성화
  닫히고 다른 패널도 없으면 GameOnly 입력 모드 복원

Widget Blueprint:
  GetPanelStateView의 bSettingsVisible로 패널 표시
  X/Y 감도 슬라이더 변경 시 SetLookSensitivity 호출
  FPS 옵션 60/120/140 선택 시 SetFpsLimit 호출
  음량은 추후 Audio Settings 또는 GameUserSettings에 연결

Character:
  DoAim에서 PlayerController의 X/Y 감도 적용
